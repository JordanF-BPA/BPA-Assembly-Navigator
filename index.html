Download for Chrome & Edge
How to install
  1. Download the ZIP, then right-click it in Windows and select Extract All. Keep the extracted folder somewhere permanent.
  2. In the browser you use for drawing links, type chrome://extensions for Chrome or edge://extensions for Edge into the address bar.
  3. Turn on Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.
  4. Check that BPA Navigator direct-tab helper is enabled. Allow its requested site access, then refresh your open Trimble Connect tabs.
  5. Open your drawing link again. Use the same browser and profile where you installed the helper.

Already installed? Enable or reload the helper on the Extensions page, then refresh Connect. Downloading the ZIP alone does not install it.

Open download and installation guide in a new tab if the download is blocked inside Connect.

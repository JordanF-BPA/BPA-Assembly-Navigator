BPA

Navigator helper

For Chrome and Microsoft Edge on Windows

Install once, then reopen your drawing link

The helper adds automatic tab handling and sign-in recovery to BPA Navigator. Chrome and Edge use the same download.

Download for Chrome & Edge
  1. Extract the download. Right-click the ZIP in Windows and select Extract All. Keep the extracted folder somewhere permanent; the browser loads the extension from that folder.
  2. Open your browser’s Extensions page. Type chrome://extensions into Chrome’s address bar, or edge://extensions into Edge’s address bar.
  3. Turn on Developer mode. Choose Load unpacked, then select the extracted folder containing manifest.json. Select the folder, not the ZIP or a file inside it.
  4. Enable the helper. Confirm that BPA Navigator direct-tab helper is enabled and allow its requested site access.
  5. Refresh Connect. Refresh your open Trimble Connect tabs, then click your original drawing link again. The drawing links do not need to change.

Already installed?

Enable or reload the helper on the Extensions page, then refresh Connect. If you downloaded an update, extract it into your existing extension folder and click its reload button.

Use the same browser and profile for the helper and your drawing links. For links opened from a PDF reader, make that browser your Windows default. Install separately in Chrome and Edge if you use both; the helper cannot transfer drawings between browsers.

If your organisation disables Developer mode or Load unpacked, ask your IT team to help install it.

Downloading does not install the helper automatically. A missing-helper notice can only appear once Navigator loads; it cannot recover a drawing link already lost during sign-in before installation.
